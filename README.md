### Hi, I'm Christie 👋

I'm building [kornia-slam](https://github.com/kornia/kornia-slam), open-source SLAM in Rust for any
sensor and any hardware, as a maintainer in the [Kornia](https://github.com/kornia) project.

- **kornia-slam**: one system for whatever sensors a robot carries, from cameras and IMUs to LiDAR,
  radar and beyond, that fits the compute it has, from a Raspberry Pi to a workstation.
- **kornia-rs**: the crates it builds on, like
  [`kornia-algebra`](https://github.com/kornia/kornia-rs/tree/main/crates/kornia-algebra) and
  [`kornia-3d`](https://github.com/kornia/kornia-rs/tree/main/crates/kornia-3d).
- **Research**: how SLAM maps and world models can feed each other, and how AI agents can
  improve SLAM.
- **Community**: admin and Google Summer of Code mentor at [Kornia](https://www.kornia.org/),
  Rising Ambassador at [OpenUK](https://openuk.uk).
